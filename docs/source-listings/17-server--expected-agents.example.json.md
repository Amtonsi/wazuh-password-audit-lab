# `server/expected-agents.example.json`

Полный читаемый листинг файла. Это сгенерированное представление в UTF-8: BOM снят для отображения, окончания строк представлены как LF. Для запуска и сохранения исходной кодировки используем [оригинал в `code/`](../../code/server/expected-agents.example.json). Исполняемый код в оригинале сохранён побайтно.

**Назначение.** Исходный пример реестра ожидаемых АРМ для расчёта охвата и отсутствующих снимков.

**Применение.** Копируем в /etc/wazuh-password-audit/expected-agents.json; заполняем массив фактических agent_id, agent_name, os и expected.

**Особенности.** Оригинал содержит только агента 001. Для лаборатории добавлен отдельный expected-agents.lab.json на четыре ID. ID сохраняем строкой с ведущими нулями. Узлы вне реестра не увеличивают число ожидаемых.

**Происхождение.** Проверенный исходный комплект.

**Кодировка оригинала:** UTF-8 без BOM. **Объём:** 3 строк.

**SHA256 оригинала:** `8d7c3b652a747c9cf080d624b634aae68006591c638bb20289c86782621ef4e0`.

Для файлов без завершающего переноса строки перед закрывающим ограждением Markdown добавлен только разделительный LF; оригинал и его контрольная сумма остаются прежними.

## Полный код

```json
[
  {"agent_id": "001", "agent_name": "WINXP-SP2-01", "os": "Windows XP", "expected": true}
]
```
