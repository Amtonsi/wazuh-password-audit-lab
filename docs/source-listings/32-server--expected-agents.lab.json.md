# `server/expected-agents.lab.json`

Полный читаемый листинг файла. Это сгенерированное представление в UTF-8: BOM снят для отображения, окончания строк представлены как LF. Для запуска и сохранения исходной кодировки используем [оригинал в `code/`](../../code/server/expected-agents.lab.json). Исполняемый код в оригинале сохранён побайтно.

**Назначение.** Дополнительный заполненный пример реестра всех четырёх АРМ лаборатории.

**Применение.** После сверки ID используем как expected-agents.json.

**Особенности.** Создан при оформлении исходников. Перед переносом на другой стенд заменяем ID и имена его фактическими регистрациями.

**Происхождение.** Заполненный пример, подготовленный при оформлении лаборатории.

**Кодировка оригинала:** UTF-8 без BOM. **Объём:** 26 строк.

**SHA256 оригинала:** `ea37b9db6d7627c1f633a643e7ce8b4966e2d6b173cc64e0891632072df91596`.

Для файлов без завершающего переноса строки перед закрывающим ограждением Markdown добавлен только разделительный LF; оригинал и его контрольная сумма остаются прежними.
