# `wazuh-localfile.xml`

Полный читаемый листинг файла. Это сгенерированное представление в UTF-8: BOM снят для отображения, окончания строк представлены как LF. Для запуска и сохранения исходной кодировки используем [оригинал в `code/`](../../code/wazuh-localfile.xml). Исполняемый код в оригинале сохранён побайтно.

**Назначение.** Блок чтения дневных JSONL-файлов аудита паролей.

**Применение.** Объединяем один localfile с существующим ossec_config агента и применяем конфигурацию.

**Особенности.** Не заменяем этим фрагментом весь ossec.conf. Тот же источник не дублируем в локальном и групповом конфиге.

**Происхождение.** Проверенный исходный комплект.

**Кодировка оригинала:** UTF-8 без BOM. **Объём:** 6 строк.

**SHA256 оригинала:** `8ff6eea2b9370b30976906b843013b82a3ac04cf064abcdaf3887402bbb1e43f`.

Для файлов без завершающего переноса строки перед закрывающим ограждением Markdown добавлен только разделительный LF; оригинал и его контрольная сумма остаются прежними.

## Полный код

```xml
<!-- Добавляем внутрь существующего ossec_config на АРМ.
     Если этот источник уже задан через agent.conf, второй раз его не добавляем. -->
<localfile>
  <location>C:\SIEM-Audit\Password\logs\password-audit-*.jsonl</location>
  <log_format>json</log_format>
</localfile>
```
