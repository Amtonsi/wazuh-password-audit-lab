# `wazuh-group-agent.conf.example`

Полный читаемый листинг файла. Это сгенерированное представление в UTF-8: BOM снят для отображения, окончания строк представлены как LF. Для запуска и сохранения исходной кодировки используем [оригинал в `code/`](../../code/wazuh-group-agent.conf.example). Исполняемый код в оригинале сохранён побайтно.

**Назначение.** Пример централизованного подключения JSONL через группу Windows-агентов.

**Применение.** Объединяем с существующим agent.conf нужной группы; проверяем получение агентами.

**Особенности.** Файл не устанавливает сборщики и задания. На XP отдельно проверяем применение общих конфигураций; в лаборатории источник можно оставить локальным.

**Происхождение.** Проверенный исходный комплект.

**Кодировка оригинала:** UTF-8 без BOM. **Объём:** 8 строк.

**SHA256 оригинала:** `0cee632f9f618609420b52e634f9b64c5be81db9a0e13e6402bbff1e93833529`.

Для файлов без завершающего переноса строки перед закрывающим ограждением Markdown добавлен только разделительный LF; оригинал и его контрольная сумма остаются прежними.

## Полный код

```xml
<!-- Объединяем с существующим agent.conf нужной группы Windows.
     Этот файл задаёт чтение журнала; скрипты и задачи он не устанавливает. -->
<agent_config os="Windows">
  <localfile>
    <location>C:\SIEM-Audit\Password\logs\password-audit-*.jsonl</location>
    <log_format>json</log_format>
  </localfile>
</agent_config>
```
