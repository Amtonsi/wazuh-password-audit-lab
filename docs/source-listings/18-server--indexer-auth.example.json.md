# `server/indexer-auth.example.json`

Полный читаемый листинг файла. Это сгенерированное представление в UTF-8: BOM снят для отображения, окончания строк представлены как LF. Для запуска и сохранения исходной кодировки используем [оригинал в `code/`](../../code/server/indexer-auth.example.json). Исполняемый код в оригинале сохранён побайтно.

**Назначение.** Шаблон защищённого файла учётных данных Indexer; содержит только заглушки.

**Применение.** Заполняем локально /etc/wazuh-password-audit/indexer-auth.json и задаём root:root, 0600. Путь указываем в auth_file.

**Особенности.** Действительные секреты не входят в сборник. Права учётной записи должны позволять чтение источника, запись собственных производных индексов, переключение alias и retention при его включении.

**Происхождение.** Проверенный исходный комплект.

**Кодировка оригинала:** UTF-8 без BOM. **Объём:** 4 строк.

**SHA256 оригинала:** `e7687e8e9d62b7493e257cf252a80bf947a33caa21697083e289f85b3192e236`.

Для файлов без завершающего переноса строки перед закрывающим ограждением Markdown добавлен только разделительный LF; оригинал и его контрольная сумма остаются прежними.
