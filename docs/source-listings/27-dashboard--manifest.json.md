# `dashboard/manifest.json`

Полный читаемый листинг файла. Это сгенерированное представление в UTF-8: BOM снят для отображения, окончания строк представлены как LF. Для запуска и сохранения исходной кодировки используем [оригинал в `code/`](../../code/dashboard/manifest.json). Исполняемый код в оригинале сохранён побайтно.

**Назначение.** Манифест локальной сборки: ID, количество объектов и панелей, alias и ограничение выборки.

**Применение.** Используем для проверки состава перед импортом.

**Особенности.** Это не отчёт о текущем внедрении. live_imported=false относится к стадии сборки и не опровергает выполненный позднее импорт.

**Происхождение.** Проверенный исходный комплект.

**Кодировка оригинала:** UTF-8 без BOM. **Объём:** 10 строк.

**SHA256 оригинала:** `a0de0fd2e975b8d34b9e4e722078855507dc09d2d2820a820b7c81338ce30450`.

Для файлов без завершающего переноса строки перед закрывающим ограждением Markdown добавлен только разделительный LF; оригинал и его контрольная сумма остаются прежними.
