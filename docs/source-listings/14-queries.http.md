# `queries.http`

Полный читаемый листинг файла. Это сгенерированное представление в UTF-8: BOM снят для отображения, окончания строк представлены как LF. Для запуска и сохранения исходной кодировки используем [оригинал в `code/`](../../code/queries.http). Исполняемый код в оригинале сохранён побайтно.

**Назначение.** Диагностические запросы последних сводок по агентам и mapping нового пространства полей.

**Применение.** Выполняем отдельные GET-запросы в Dev Tools.

**Особенности.** Composite-список продолжаем с after_key для большого парка. Не фильтруем заранее только успешные снимки: более поздняя ошибка должна оставаться видимой.

**Происхождение.** Проверенный исходный комплект.

**Кодировка оригинала:** UTF-8 без BOM. **Объём:** 25 строк.

**SHA256 оригинала:** `f52caabc403fee9691d8da4194f1e5ea6d96710848e7cbe3f56e74ec682bd225`.

Для файлов без завершающего переноса строки перед закрывающим ограждением Markdown добавлен только разделительный LF; оригинал и его контрольная сумма остаются прежними.

## Полный код

```http
# Последние сводки по агентам, включая ошибочные.
# Не фильтруем заранее status=ok и threshold_exceeded=true.
# Для большого парка повторяем composite-запрос с after_key до конца списка.
GET /wazuh-archives-*/_search
{
  "size": 0,
  "query": {"term": {"data.password_audit_v2.kind": "summary"}},
  "aggs": {
    "agents": {
      "composite": {"size": 100, "sources": [{"agent": {"terms": {"field": "agent.id"}}}]},
      "aggs": {
        "latest": {
          "top_hits": {
            "size": 1,
            "sort": [{"timestamp": {"order": "desc"}}],
            "_source": ["agent", "timestamp", "data.password_audit_v2"]
          }
        }
      }
    }
  }
}

# Просматриваем mapping нового пространства полей.
GET /wazuh-archives-*/_mapping/field/data.password_audit_v2.*
```
