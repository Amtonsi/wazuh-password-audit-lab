# Импорт дашборда Wazuh

Дашборд отображает актуальные снимки четырёх АРМ. Перед импортом убеждаемся, что агенты передают `password_audit_v2`, Filebeat индексирует archives, а серверный обработчик публикует `lab-password-audit-current`.

## Проверяем источник

В Dev Tools выполняем:

```http
GET /_alias/lab-password-audit-current

GET /lab-password-audit-current/_search
{
  "size": 10,
  "query": {"term": {"document_kind": "host"}},
  "sort": [{"agent_id": "asc"}]
}
```

Ожидаем документы АРМ с `snapshot_complete=true` и пригодным `host_state`, временем измерения и `valid_until`. Одна регистрация агента Active ещё не доказывает доставку снимка.

## Импортируем сохранённые объекты

1. Открываем Wazuh Dashboard и используемый рабочий tenant.
2. Переходим в управление Saved objects.
3. До обновления собственных объектов сохраняем их экспорт.
4. Импортируем [Wazuh-Password-Audit-v2.ndjson](../code/dashboard/Wazuh-Password-Audit-v2.ndjson).
5. Проверяем четыре объекта: три визуализации и один dashboard.
6. Открываем «Контроль паролей локальных учётных записей — АРМ» с ID `lab-password-audit-v2-overview`.

Для локальной лаборатории адрес имеет вид:

```text
https://192.168.179.20/app/dashboards#/view/lab-password-audit-v2-overview
```

При другом адресе сервера заменяем только адрес. В выполненном развёртывании импорт использовал фактический UI-контекст без дополнительного `securitytenant` header; явный другой tenant может создать объекты, невидимые в обычном списке.

## Сверяем отображение

Верхние карточки показывают охват ожидаемых АРМ, активные локальные записи старше порога, индивидуальную бессрочность и АРМ без свежих полных данных. Таблица АРМ содержит состояние сбора, таблица пользователей — сведения по каждой записи.

Код сохраняет обновление раз в 60 секунд. Панели читают текущий alias, поэтому общий исторический timepicker и DQL к ним не применяются. Историю исследуем отдельно в Discover через `wazuh-archives-*`.

В контрольной проверке 15 ноября 2026 года показаны 4/4 АРМ, 4 превышения, 7 бессрочных признаков и 0 отсутствующих снимков. Это зафиксированный результат; актуальные числа зависят от последнего сбора.
